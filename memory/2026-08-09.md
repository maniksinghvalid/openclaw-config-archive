
## Heartbeat fix: qmd stale-index false alert (03:35 UTC)
- Heartbeat executor reported "qmd ALERT: index is stale (171h old)" even after `qmd update` succeeded.
- Root cause: qmd index runs in SQLite WAL mode — writes go to `index.sqlite-wal`, so main `index.sqlite` mtime stayed at Aug 2 while WAL was fresh. The check only looked at the main file.
- Fix: `scripts/heartbeat-executor.js` `checkQmd()` now bases freshness on the newest of `index.sqlite` and `index.sqlite-wal` (shm ignored — touched on every connection open, not a write signal).
- Verified: `HEARTBEAT_FORCE_CHECK=qmd` now returns OK; normal run returns OK. Syntax checked with `node --check`.
